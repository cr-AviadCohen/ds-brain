# AIDRA-LOCAL

Welcome to the complete documentation hub for AIDRA-LOCAL (Advanced Intelligence-Driven Risk Assessment - Local Deployment). This directory contains exhaustive documentation covering every aspect of the system: architecture, agents, analysis pipelines, evidence frameworks, threat intelligence, configuration, deployment, visualization, and integrations.

Git - https://github.com/cr-ItamarHershko/AI-DRA/tree/dev

---

### What is AIDRA-LOCAL

AIDRA-LOCAL is a production-grade, evidence-first malware analysis pipeline featuring multi-agent LLM reasoning. It was originally built as a Jupyter notebook exceeding 40,000 lines of code and has been professionally refactored into a maintainable Python package with 117+ core modules and 109,271+ lines of analytical code. The system specializes in PowerShell malware detection with gated MITRE ATT&CK mapping, multi-layer deobfuscation, and multi-agent consensus-driven verdict generation.
