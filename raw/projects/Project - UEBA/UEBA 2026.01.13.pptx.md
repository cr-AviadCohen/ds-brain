# The Problem
Traditional security methods often fail to detect sophisticated threats.
Static, rule-based systems create excessive alerts and cause analyst fatigue.
A single pattern for all users misses subtle and unique anomalous activity.
Pattern tailored for specific use-cases may generate high false positives.
Need for advanced analytics to find statistical outliers in specific user behavior.

# Project Goal
User and Entity Behavior Analytics (UEBA)An approach for threat detection that leverages advanced analytics of anomalous behavior of users, hosts and other entities within an organization’s information technology infrastructure, in order to detect threats beyond traditional security or high risk event correlation methods.
Project Goal:Develop a Anomaly Detection Machine Learning (ML) based model for UEBA
The model will be trained on baseline activity of users/entities for the detection of abnormal activity (statistical outliers).
The detected anomalies are not necessarily malicious per se but indicates on unusual activity and may be used to escalates suspected behavior.

# EMPOW approach
Cybereason has previously acquired a patent relevant to UEBA.
The EMPOW solution relies on detection of brute force/password guessing by sliding windows analysis as well as using geolocation for detection of impossible travel patterns. Then it uses fuzzy logic to provide a nuanced scoring (rather than a binary alert).
This solution is not an anomaly detection in a statistical sense - which is the detection of outliers from a population, but rather engines for detection of pre-defined unusual user behavior.

# FortiGate Firewall Dataset: Per-User Models
Features with low variance or highly correlated (user-specific) were removed so each user has effectively 54-84 features.
A cascade of several anomaly detection models were trained for each user.
Indeed data is very limited but the models were compared in the following way:
Each model trained on user X was applied on another user Y.
We expect that different users may have same activity patterns or different.
Some users have vast range of activity and some narrow.
Therefore we expect to see artificial anomalies in some of the users.
