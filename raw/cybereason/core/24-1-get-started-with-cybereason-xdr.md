## Configure log exporting from your integrated platforms

Before you can use data from XDR log sources and integrations,


you must enable the data or log export from integrated platforms.


For details on how to configure these exports, select your


[integrations from the Cybereason Integrations (/s/integrations)](https://nest.cybereason.com/s/integrations)
page and select the **Configure** tab from the integration


documentation page.

## Connect third-party integrated


Add supported integrations in the **Connect** screen and enter


configuration/connection details to connect Cybereason XDR to

your integrated platforms.


Some third-party integrated platforms share data using an API

cloud feed, while others require the Cybereason XDR on-site


collector agent to securely forward the logs.


For details on how to connect each integration, select your


[integrations from the Cybereason Integrations (/s/integrations)](https://nest.cybereason.com/s/integrations)
page and select the **Configure** tab from the integration


documentation page. For details on how to install an on-site

[collector agent, see Add an On-Site Integration (/s/knowledge-](https://nest.cybereason.com/s/knowledge-base?article=24-1-add-an-on-site-integration&language=en_US#add-an-on-site-integration)

## Onboard data from integrated platforms


After you configure log exports in integrated platforms and add
the integration details in Connect, the data begins to flow between


[your integrated platforms and Cybereason XDR. You can view the](https://nest.cybereason.com/s/knowledge-base?article=24-1-use-cybereason-connect&language=en_US#view-your-integrations)

[integration status in Connect (/s/knowledge-base?article=24-1-](https://nest.cybereason.com/s/knowledge-base?article=24-1-use-cybereason-connect&language=en_US#view-your-integrations)


[use-cybereason-connect&language=en_US#view-your-](https://nest.cybereason.com/s/knowledge-base?article=24-1-use-cybereason-connect&language=en_US#view-your-integrations)

[integrations) and ensure that Suspicious events are displayed in](https://nest.cybereason.com/s/knowledge-base?article=24-1-use-cybereason-connect&language=en_US#view-your-integrations)


the **Suspicious events** screen (if there are suspicious events for

the integration).


In the **XDR Dashboard**, view a summary and trends in XDR data

from integrated data sources, and see overall integration health to


identify problems as soon as possible.


[For details on the XDR dashboard, see XDR Dashboard](https://nest.cybereason.com/s/knowledge-base?article=24-1-xdr-dashboard&language=en_US#xdr-dashboard)
