Enable Personal firewall control
1. In your sensor policy, navigate to the Endpoint controls
screen.
2. In the Endpoint Controls screen, locate the Personal firewall
control section and set the toggle to On.
When you switch the Personal firewall control toggle to On,
the Domains, Private Networks, and Public Networks
checkboxes are automatically selected.
Note
When you enable Personal firewall control on a policy for Linux
endpoint machines, the Cybereason platform deletes any
firewall rules that previously existed on the endpoint.
