These MalOps are disabled by default. Open a Technical
Support (/s/support) case to enable these MalOps.
There are multiple MalOps associated with Potentially Unwanted
Programs. The 'Cybereason Threat Intelligence identified an
Unwanted Executable' MalOp is triggered when a process image
file hash is identified as a Potentially Unwanted Program by
Cybereason Threat Intelligence. The 'Cybereason Threat
Intelligence identified an Unwanted Module' MalOp is triggered
when a process loads a module identified as a Potentially
Unwanted Program by Cybereason Threat Intelligence. The
'Process tampered with Windows Defender' MalOp is triggered
when a process interferes with the Windows Defender settings.
Potentially unwanted programs are programs that are identified as
suspicious and potentially malicious but it is not clear of the exact
nature of the application. The Cybereason platform detects when
a file, a process image file, or a module associated with a process
is classified as a potentially unwanted program.
Supported OS for these MalOps: Windows, Mac OS, and Linux
These MalOps are part of the Low Priority group.
Examples of behavior that can trigger this MalOp:
Classification of a file or process as a Potentially Unwanted
Program
Classification of a module as a Potentially Unwanted Program
Indications of a module or a process behaving like a
Potentially Unwanted Program
