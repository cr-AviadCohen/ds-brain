database. At least 250 MB of storage is required regardless of


the update. Environments that lack these resources cannot

operate correctly.

In some virtual desktop environments, end users may experience


slower logon times if a large number of virtual machines connect

at the same time. To address this issue, contact Technical Support


and request a sensor configuration change so that sensor
collection starts within a configurable time range after the machine


starts. The default time range is 30-90 seconds.

## Virtual Application environments


You install a Cybereason sensor on the underlying server


operating system that supports the virtual application platform.


You do not need to install the Cybereason sensor on the Virtual


Applications (VA), such as Microsoft Word.
