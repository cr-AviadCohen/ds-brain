## 2. Install Cybereason sensors

Sensors collect security data from your endpoints to help discover

advanced threats. On endpoint machines, the sensor can protect


your endpoints against malware with prevention-based NGAV

features.


You can install sensors on PCs and server machines running

Windows, Mac, or Linux OS operating systems.


**To install Cybereason sensors:**


[1. Verify you've met the Pre-installation Requirements and](https://nest.cybereason.com/s/knowledge-base?article=24-1-pre-installation-requirements-and-instructions&language=en_US#pre-installation-requirements-and-instructions)
