## Event classes


In the header, the **Event class** field lists a category for the event.


The following **Event classes** are possible in the syslog:


MALOP


MALWARE

USERACTION

## Event names


The **Event name** field describes the specific event for this syslog

message. The following tables list Event names by Event class,


along with descriptions of the event that triggered the message.

## MalOp event class event names






|Event name|Triggering action|
|---|---|
|Malop Created|The Cybereason platform created a new<br>MalOp.|

## UserAction event class event names

The UserAction event class categorizes user events into **action**
**groups** . Action groups are noted in the event name field of the


CEF header, followed by a slash and the event name, as seen in

the following example:

```
 CEF:0|Cybereason|Cybereason|2016.5.4|Use

 rAction|MALOP_INVESTIGATION/ChangeMalopS

 tate|0|

```
