# STIX

> Structured Threat Information Expression — OASIS standard for threat-intel exchange (STIX 2.1) — schema target for [[AIDRA]] and [[AI Assistant]].

## Owner / vendor

OASIS Cyber Threat Intelligence (CTI) Technical Committee — originally stewarded by MITRE; STIX 2.x is the current OASIS-ratified standard.

## Integration surface

- JSON schema (STIX 2.1) — typed objects for indicators, malware, threat actors, campaigns, relationships.
- TAXII feed — companion HTTPS-based transport protocol for STIX exchange.

## Data flow

External — threat-intel producers emit STIX bundles; consumers ingest via TAXII or file drop. DS-team usage: candidate output schema for threat reports generated by [[AIDRA]] and structured-IOC output for [[AI Assistant]] threat-intelligence agents.

## Current usage

Referenced as a schema target — not yet wired up as a production export format.
