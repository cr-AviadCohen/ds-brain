# Anthropic

> AI safety lab; vendor of the Claude family of LLMs used across the DS
> team's agentic projects.

## What they do

Frontier AI research lab and provider of the Claude family of large
language models (Claude Opus / Sonnet / Haiku). Also publisher of the
Model Context Protocol ([[MCP]]) standard and Claude Code / Claude
Desktop tooling that the DS team consumes day-to-day.

## Relationship to DS team

Vendor. Claude API powers multiple DS-team projects: [[Hunter]] (AI
hunting interface), [[AI Assistant]] (NL platform interface),
[[AIDRA]] (multi-agent risk assessment), [[OwlBot]] (Notion MCP
server), [[Pixel Agents]] (autonomous agent framework). Claude Code is
the default development environment for this wiki and several agentic
codebases.
